# Dalili Pilot Feedback Guide

Use `/feedback` after each demo or test session. Capture who reviewed the product, which area they reviewed, a 1-5 usefulness rating, what worked, what was confusing, and what should improve next.

Recommended pilot questions:

1. Which part of Dalili would save you the most time?
2. Which output would you trust enough to use in a donor report?
3. Which part still feels unclear or risky?
4. What must be added before your organisation would pay for this?
5. Which role in your organisation would use it most often?

Suggested target for a usable pilot: at least 10 feedback records from M&E officers, researchers, consultants, programme managers, and one senior approver.
